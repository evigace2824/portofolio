# Password Security Analyzer

Password Security Analyzer is a web-based application designed to evaluate password strength and complexity.  
The tool provides real-time feedback based on password composition, entropy estimation, simulated crack time, and basic security policy validation.

---

## Overview

This application analyzes user-entered passwords by examining character diversity and structural complexity.  
It estimates password unpredictability using entropy calculations and presents a visual strength indicator to improve user awareness of password security.

The project was developed as part of a practical exercise focused on applying fundamental cybersecurity concepts to a user-facing interface.

---

## Features

- Password strength classification
- Entropy-based complexity estimation
- Estimated crack time simulation
- Attack resistance visualization
- Password policy compliance checker
- Threat level indicator
- Real-time feedback

---

## How It Works

The analyzer evaluates passwords by calculating entropy based on the character sets used:

- Lowercase letters
- Uppercase letters
- Numbers
- Special characters

Based on the entropy value, the system estimates:

- Password strength level
- Approximate crack time
- Resistance to common attack scenarios
- Compliance with standard password policies
